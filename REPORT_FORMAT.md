# Report format

Submit the complete report generated by the **OmniDR agent harness** for each
task. Copy its output directory intact so the HTML page, report data, and local
resources remain together.

## Directory layout

Place each report at `reports/{model_name}/{task_id}/`, using the public task ID
from your downloaded `OmniDR-Bench.jsonl`, such as `OmniDR-Bench-v0-0001`. `model_name` identifies the
evaluated model.

```text
reports/
└── {model_name}/
    └── OmniDR-Bench-v0-0001/
        ├── index.html         # required
        ├── js/
        │   ├── data.js        # required
        │   └── ...            # report scripts
        ├── css/               # if present
        ├── assets/            # if present
        ├── img/               # if present
        └── ...                # other original report resources
```

`index.html` and `js/data.js` must be present and nonempty. Keep all other files
and directories supplied with the report, including scripts, stylesheets,
images, videos, and saved source pages; their names may differ from this example.

Preserve the original resource layout and keep relative paths usable from the
report. Include all local files referenced by the page so it remains viewable
after copying.

An extra wrapper at `reports/{model_name}/{task_id}/report/` is also supported.

## Check an existing report

After the environment and benchmark data are set up as described in the
[README](README.md), run from the repository root:

```bash
python evaluate.py --reports-dir ./reports --data-dir /path/to/OmniDR-Bench-data --validate-only
```

This checks report discovery and required inputs without judge API calls or
browser rendering. See the [README](README.md) for running full evaluation.
